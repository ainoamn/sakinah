# سكينة (Sakinah)

موقع قراءة عام، بهوية عمانية وإباضية، مع حساب اختياري ومكتبة PDF.

وثيقة المتطلبات وسجل التسليم من موجات البناء: `docs/PROJECT-BRIEF.md`.
سجل تطبيق حزمة كي مي V12: `docs/KIMI-V12-PACKAGE.md`.

## النشر والروابط

- GitHub: https://github.com/ainoamn/sakinah
- Vercel (إنتاج): https://sakinah-swart.vercel.app
- لوحة Vercel: https://vercel.com/bhdom89-8158s-projects/sakinah

الواجهة العامة المنشورة على Vercel هي الملفات في `public/site/` عبر `vercel.json` (مخرجات ثابتة بلا بناء Next). أي دفع إلى الفرع `main` يُعاد نشره تلقائيًا بعد ربط المستودع.

رفع ونشر يدوي من مجلد المشروع:

```
git add -A
git commit -m "Update Site source"
git push origin main
vercel deploy --prod --yes
```

> عند تثبيت دومين رسمي: حدّث `canonical` و`og:url` وبيانات JSON-LD في
> `public/site/index.html` و`robots.txt` و`sitemap.xml` ليستخدم الدومين الجديد.

## مصدر الموقع

- `public/site/`: الواجهة العربية والإنجليزية والمصحف والأصول والكتب؛ هذا هو مصدر الواجهة الذي يُعدل.
- `public/site/state.js`: حفظ فوري محلي مع نسخة IndexedDB للاستعادة؛ لا يُرسل إلى خادم (مرايا IndexedDB مجمّعة كل 300ms لتخفيف الكتابات المتكررة).
- `public/site/device.js`: استئناف التطبيق المثبّت وتصدير/استيراد نسخة التقدم.
- `public/site/mobile.css`: تنسيقات الشاشات الضيقة وأدوات نسخة التقدم.
- `app/api/account/route.ts`: واجهة الحساب المحمية بهوية Sites مع تحديد معدل الكتابة واستبقاء النشاط 90 يومًا؛ لا يُؤخذ معرف المستخدم من الطلب.
- `db/schema.ts` و `drizzle/`: مخطط الحساب والنشاط وترحيله.
- `.openai/hosting.json`: هوية الموقع وربط D1 باسم DB. الجمهور عام.
- `dist/`: ناتج بناء مولد؛ لا تعدله.

## التشغيل والتحقق

```
npm run dev -- --port 5173 --hostname 127.0.0.1
node validate.cjs
node scripts/test-device-state.cjs
python scripts/test-account.py
```

اختبار الحساب يستخدم محاكاة الدخول المحلية Seedy فقط. التشغيل المحلي يحتاج تطبيق ترحيل D1 قبل اختبارات الحساب؛ راجع README الخاص ببنية Sites عند تعديل المخطط.

البناء المعتمد لـ Sites عبر سكربت مولد بنية Sites لديك، ثم:

```
vercel deploy --prod --yes
```

## السلوك

القراءة متاحة دون حساب. تسجيل الدخول الاختياري باستخدام ChatGPT يحفظ خطة الورد وزيارات الحساب والأذكار المكتملة والصفحات التي يعلّمها المستخدم كمنتهية وعلامة الصفحة. البيانات مفصولة على الخادم بمعرف هوية المستخدم. طلبات الكتابة تتحقق من المصدر والمدخلات، وتستخدم معرف حدث لمنع التكرار، ومعدل كتابة 90/دقيقة لكل مستخدم.

المصحف يدعم العرض الأفقي والتمرير الطولي مع تحميل الصفحات عند الحاجة. الصور تأتي من آيات بجامعة الملك سعود؛ النص المحلي بديل. الكتب الخمسة محفوظة في 135 بطاقة مصورة مع نسبة المصدر. 33 ملف PDF للأذكار والأدعية وفئاتها، إضافة إلى ملفات الكتب الخمسة. أزرار المشاركة تستخدم مشاركة النظام عند الدعم، والتنزيل عند عدم توفر مشاركة الملفات.

الواجهة باللغتين؛ النصوص الدينية الأصلية والكتب المرفوعة بالعربية. مواقيت الصلاة من AlAdhan مع اختيار المدينة والطريقة، وهي حسابية وليست الجدول الرسمي العماني. الحكمة اليومية محتوى تحريري موسوم بوضوح وليست حديثا منسوبا.

تنبيه المتصفح يعمل أثناء فتح الموقع وبإذن المستخدم. لعمل التذكير بعد الإغلاق، ينزل المستخدم ملف ICS ويستورده في تقويمه مع تفعيل التنبيهات. لا توجد خدمة إرسال بريد أو إشعارات Push في الخلفية.

## الكتب والحقوق

الحقوق والمصادر في `public/site/assets/CREDITS.txt` و `QURAN-LICENSE.txt`. كتب المستخدم تحفظ نصوصها وصفحاتها الأصلية، مع غلاف سكينة دون ادعاء تأليفها. استخراج بعض خرائط PDF غير موثوق لذا عُرضت الصفحات صورا ويمكن تكبيرها. `scripts/build_books.py` يعيد إنتاج الأصول من الملفات المحلية الأصلية، ويدعم `--exports-only`.

المحتوى لا يمثل مراجعة علمية إباضية أو تخريجا مستقلا، ولا تدعي المبادرة اعتماد جهة رسمية.

## الإصدار الحالي (V14 — الشاشة الأفقية ومحاذاة السور)

- زر واحد «السورة» يفتح قائمة بحث مع مربعات اختيار. المربع بجانب اسم السورة على كل عرض شاشة، والضغط على الاسم ينتقل إليها، و«عرض المختارة فقط» يبقي التقليب داخلها (`quranSelectedSurahs`).
- المصحف والأذكار والمكتبة في الوضع الأفقي على الهاتف والآيباد تملأ ارتفاع الشاشة: شريط واحد، وإخفاء ترويسة التركيز، وصفحتان متجاورتان عندما يسمح العرض.
- نص القرآن (نحو 2MB) يُحمَّل عند فتح المصحف أو الأذكار أو البحث، لا مع الرئيسية.
- مواقيت الرئيسية على الشاشات العريضة شريط داكن تحت الصورة: الصلاة القادمة والسابقة، ثم الصلوات الست في صف واحد.
- شاشة الذكر على العرض العريض تُبقي نص الدعاء وزر التسبيح والتنقّل معًا داخل الشاشة، والنص الطويل يتمرّر داخل البطاقة.
- بطاقات المكتبة على الهاتف تعرض الشعار والعنوان كاملين دون قصّ، وشريط الأعلى لا يفيض عن العرض.
- كتب المكتبة تُفتح بالتمرير الطولي للقراءة، مع خيار عرض الصفحات، وخط الأدعية والكتب بخط المصحف العثماني بمحاذاة مرتّبة.
- أدوات المصحف الإضافية تُجمع في زر ⋯، والشريط يبقى للسورة والصفحة مع تحميل مسبق واستجابة أسرع للتسبيح.
- إصدار الواجهة/التخزين المؤقت: `sakinah-v64-focus-full`.

### V12 — إصلاحات أمنية وتقنية

- إصلاح رابط canonical وبيانات JSON-LD إلى نطاق الإنتاج، وإضافة og:image وبطاقات Twitter.
- إضافة `robots.txt` و`sitemap.xml`، ودمج طلبات Google Fonts في طلب واحد.
- رؤوس أمنية إضافية في Vercel (CSP، X-Frame-Options، Permissions-Policy) وتخزين طويل لمجلد assets.
- إصلاح مفتاح الـ cache النسبي في `sw.js` ليعمل الرجوع دون اتصال فعليًا.
- تحديد معدل الكتابة لكل مستخدم (90/دقيقة) + سقف 200 مفتاح تقدم + تنظيف دوري لسجل النشاط الأقدم من 90 يومًا + تحقق دقيق لعلامة الصفحة حسب عدد آيات السورة.
- مرايا IndexedDB مجمّعة كل 300ms لتخفيف ضغط الكتابة أثناء التسبيح السريع.
- اختصارات PWA موحدة كلها بـ `?launch=app`، وCI على GitHub Actions يشمل فحص رفع إصدار sw.js.
