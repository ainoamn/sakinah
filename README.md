# سكينة | قرآن وذكر ودعاء

موقع عربي باتجاه RTL، بروح عمانية وهوية إباضية، مع توثيق للمصادر وحدود المراجعة العلمية.

## التشغيل

من هذا المجلد شغّل:

    python -m http.server 4173 --directory dist

ثم افتح http://127.0.0.1:4173

لا يحتاج الموقع إلى تثبيت حزم أو بناء. الملفات المنشورة في dist.

## المحتوى

- مصحف كامل: 114 سورة و6236 آية، quran-uthmani من Al Quran Cloud، محفوظ دون إعادة صياغة.
- 90 مادة مصنفة من القرآن والأذكار والأدعية والرقية والصلاة على النبي والتسبيح والحمد.
- قائمة الأسماء الحسنى المشهورة مع بيان حدود نسبتها.
- بحث شامل، مفضلة، علامة قراءة، حجم خط، وضع ليلي، سبحة، ومتابعة أعمال يومية.
- التخزين محلي في المتصفح؛ لا توجد مزامنة سحابية.
- التلاوات والخطوط الخارجية تتطلب اتصالا بالإنترنت.

## التحقق

    node --check dist/app.js
    node --check dist/data.js
    node validate.cjs

جرى فحص تنقلات القراءة، آية الكرسي في سورة البقرة، المفضلة، البحث، السبحة، الأسماء، متابعة الأعمال، قائمة الهاتف والوضع الليلي في المتصفح.

## المراجعة العلمية

المكتبة منتقاة وليست حصرا لكل الأدعية. لا تمثل الفحوص التقنية تدقيقا شرعيا أو اعتمادا إباضيا. تذكر المراجع بجوار النصوص. راجع أهل الاختصاص قبل تقديم الموقع بوصفه مرجعا مذهبيا معتمدا.

## الحقوق

انظر dist/QURAN-LICENSE.txt. الرسوم والتصميم والشفرة أُنشئت لهذا المشروع. لا توجد صور منسوخة من المواقع المرجعية.

## الاستضافة

هوية الموقع وإعدادات الاستضافة في .openai/hosting.json. احتفظ بمعرف الموقع عند تحديثه، ولا تنشئ موقعا جديدا للتحديثات.


## التحديث الثاني

- الموقع عام دون اشتراط تسجيل الدخول.
- مصحف مصور مع تقليب الصفحات، صفحتين للشاشات الواسعة وصفحة للهاتف، الانتقال بالسورة والجزء والصفحة، السحب والسهمين، ووضع التركيز.
- صور الصفحات من مشروع آيات بجامعة الملك سعود عند الطلب، مع نص محلي بديل؛ تتطلب الصور اتصالا بالإنترنت.
- خرزة عد تفاعلية في كل ذكر؛ حفظ العداد محليا، إعادة العد، وأعداد واردة بمصادرها أو أهداف شخصية مقترحة مميزة بوضوح.
- شعار خاص مولد بالصور، ومعرض صور حقيقية للجوامع العمانية. انظر dist/assets/CREDITS.txt وlogo-prompt.txt للحقوق والتفاصيل.
- فحص متصفح: أول المصحف وآخره، منع تجاوز 604، تغيير العرض بين صفحة وصفحتين، حفظ الموضع، وضع التركيز، العدادات واستمرارها بعد إعادة التحميل.
